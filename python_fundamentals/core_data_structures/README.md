# Python - Core Data Structures & Functions / Modules

This repository contains Python projects and exercises completed as part of the Holberton School curriculum. The focus here is on mastering Python fundamentals, including modularity, imports, execution guards, and core data structures.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All your files will be interpreted/compiled on Ubuntu 20.04 LTS using python3 (version 3.8.5)
* All your files should end with a new line
* The first line of all your files should be exactly `#!/usr/bin/env python3`
* A `README.md` file, at the root of the folder of the project, is mandatory
* Your code should use the `pycodestyle` (version 2.7.*)
* All your modules should have documentation (`python3 -c 'print(__import__("my_module").__doc__)'`)
* All your functions should be documented (`python3 -c 'print(__import__("my_module").my_function.__doc__)'`)

## Files & Description

| Filename | Description |
| -------- | ----------- |
| `print_list_integer.py` | A function that prints all integers of a list using `:d` formatting. |
| `calculation.py` | A program that imports basic arithmetic functions and prints results. |
| `variable_load.py` | A program that imports a variable from another module. |
