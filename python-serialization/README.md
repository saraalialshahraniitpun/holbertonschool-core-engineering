# Python - Serialization

This directory contains Python scripts covering various data serialization and deserialization formats:
- **task_00_basic_serialization.py**: Basic JSON serialization and deserialization.
- **task_01_pickle.py**: Serializing and deserializing custom classes using `pickle`.
- **task_02_csv.py**: Converting CSV data into JSON format using `csv` and `json` modules.
- **task_03_xml.py**: Serializing and deserializing dictionaries using XML (`xml.etree.ElementTree`).
